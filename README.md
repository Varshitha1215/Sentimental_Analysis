# Sentiment Analysis Platform

A production-ready full-stack sentiment analysis platform that helps businesses analyze large volumes of customer feedback, reviews, and social media data using AI/ML models.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js
- **ML Engine:** Python

## Supported Models

- VADER
- DistilBERT
- RoBERTa
- Ensemble model (up to **98% accuracy** in benchmarked validation datasets, tracked with precision/recall/F1)

## Core Capabilities

- Fast parallel processing (**4–5x faster than single-worker sequential processing** on high-volume batch workloads)
- Batch file uploads for **CSV/XLSX up to 50MB**
- Real-time visualizations
- Trend analysis for sentiment over time
